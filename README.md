# ✦ ZENITH SCHOOL OF AI – Student Registration System

A modern and futuristic Student Registration Website built using HTML, CSS, and JavaScript.

This project provides an attractive registration interface where students can enter their personal, academic, contact, and guardian details.

## 🚀 Features

- Modern Dark UI with Neon Gradient Design
- Responsive Design for Mobile and Desktop
- Student Personal Information Form
- Student Photo Upload with Live Preview
- Password and Confirm Password Validation
- Date of Birth Selection
- Gender Selection
- Academic Details and Course Selection
- Technical Skills and Hobbies Selection
- Address and Contact Information
- Parent / Guardian Details
- Emergency Contact Information
- Automatic Demo Student ID Generation
- Registration Success Popup
- Reset Form Functionality

## 🛠️ Technologies Used

- HTML5 – Website Structure
- CSS3 – Styling and Responsive Design
- JavaScript – Form Validation and Functionality

## 📋 How It Works

1. Students fill in their personal information.
2. Students enter their academic details.
3. Students upload their profile photo.
4. JavaScript validates the required information.
5. A demo Student ID is generated.
6. A registration success popup displays the submitted details.

## 🎯 Project Objective

The main objective of this project is to develop a modern and user-friendly student registration interface while practicing HTML, CSS, and JavaScript.

## ⚠️ Important Note

This is a frontend-only project.

- Student information is not permanently stored.
- No database or backend is connected.
- Generated Student IDs are for demonstration purposes only.
- Do not enter real passwords or sensitive personal information.
